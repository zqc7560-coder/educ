# 校园失物招领系统 · 部署文档（M12）

> 实测环境：Docker Desktop（WSL2 后端）+ mysql:8.0 / redis:7-alpine / nginx:1.25-alpine /
> eclipse-temurin:21-jre。全链路一键验收 10/10 PASS（见 §6）。

## 1. 架构总览

```
浏览器 ──▶ nginx:80 ─┬─ /            → SPA 静态文件（前端构建产物，history 路由兜底）
                    ├─ /api/*       → 反代 lf-server:8081（Spring Boot，X-Forwarded-* 透传）
                    └─ /uploads/*   → 图片直出（named volume，nginx 先试文件 404 再回退）
lf-server ─┬─▶ mysql:3306（lost_found_db，utf8mb4；首启自动灌 schema.sql+data.sql）
           ├─▶ redis:6379（缓存/PV 计数/黑名单/防刷锁；appendonly 持久化）
           └─▶ /app/uploads（named volume lf-uploads，上传件持久）
```

四容器编排见 `deploy/docker-compose.yml`；每个服务的 healthcheck 全配齐——`depends_on: condition: service_healthy` 级联等待，杜绝"应用抢跑数据库"假启动。

## 2. 一键部署（演示/验收）

```bash
cd ../frontend && npm install && npm run build   # nginx 直接挂载 dist（不引 node 构建容器）
cd ../deploy
cp .env.example .env      # 填 4 个口令（生成方法见模板内注释），chmod 600 .env
docker compose up -d --build
# 访问 http://localhost:8088（宿主端口映射；本机 80 被博客容器占用）
```

镜像构建：后端多阶段（maven:3.9-eclipse-temurin-21 编译 → temurin:21-jre 运行），
编译阶段带 `backend/docker/settings-aliyun.xml` 镜像源 + BuildKit cache mount——
本机实测**第二次起全量构建 37s**（依赖全缓存，只有业务代码重编）。

## 3. 环境变量（.env，全部有 compose 插值）

| 键 | 用途 | 备注 |
|---|---|---|
| MYSQL_ROOT_PASSWORD | mysql root 口令 | 应用连接也用它（毕设单账号简化）；库名 lost_found_db |
| REDIS_PASS | redis requirepass | compose 内 redis 服务与 healthcheck 共用 |
| LF_JWT_SECRET | JWT 签名密钥 | ≥64 字符随机；丢失=全员登出 |
| LF_ADMIN_PASSWORD | admin 首启引导口令 | 留空则默认 Admin@123 演示口径；AdminBootstrapRunner 首启创建，之后以 DB 为准 |

真实 `.env` 被 `.gitignore` 忽略，仓库只带 `.env.example` 模板。

## 4. 数据初始化

- **空卷首启**：mysql entrypoint 按文件名序执行 `01_schema.sql`（建库+22 表）→
  `02_data.sql`（幂等种子：角色/权限/字典/示例公告/敏感词/系统参数，全 INSERT IGNORE）。
- **中文种子不乱码的钥匙**：mysql 服务 environment 里 `LANG: C.UTF-8`（compose 已配）。
  教训实录：镜像默认 LANG 为空时，entrypoint 客户端按 latin1 解释 UTF-8 脚本字节，
  公告标题入库即双重编码乱码（`欢迎…`→`æ¬¢è¿—…`）——本机裸命令行灌库要加
  `--default-character-set=utf8mb4`，容器路径要设 LANG，同一课的两端。
- **admin 账号**：由应用 `AdminBootstrapRunner` 首启用 LF_ADMIN_PASSWORD 创建（幂等）。

## 5. 生产加固（可选叠加）

```bash
docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d
```

override 差异只做加法：lf-server 只暴露内网（去掉宿主端口）、nginx 挂 443 与证书卷注释位、容器 restart: always、资源上限。

## 6. 一键验收脚本

```bash
cd deploy && bash scripts/verify-deploy.sh        # 起栈→等 healthy→冒烟→拆栈→报告
KEEP_UP=1 bash scripts/verify-deploy.sh           # 通过后保留运行中栈
```

冒烟 10 项（全部走 nginx 宿主口，不绕过反代）：health / 公告种子中文无损 / 分类字典 / 物品列表 / admin 登录(引导器) / 审核队列 / 看板聚合 / SPA history 兜底 / /uploads 反代段 / mysqldump→gzip 备份管道。本机实跑 **10/10 ALL_PASS**。

## 7. 备份与恢复

```bash
# 每日 03:00（crontab：0 3 * * * /usr/local/bin/lf-backup.sh）
bash scripts/backup-mysql.sh          # 口令走 MYSQL_PWD 不进命令行；保留 14 份自动过期
bash scripts/restore-mysql.sh /path/lf_2026-11-12_0300.sql.gz   # zcat 管道导入不落盘
```

上传件目录（volume lf-uploads）备份：`docker run --rm -v lf-uploads:/data -v $(pwd):/backup alpine tar czf /backup/uploads_$(date +%F).tar.gz -C /data .`

## 8. 本地开发模式（不走容器）

```bash
# 后端：IDE 或命令行起 Spring Boot（8081），需本机 MySQL(lost_found_db root 口令在 backend/.env)
#       + Redis（E:\develop\redis-8.10.1\start-redis.vbs，db1）
cd backend && mvn spring-boot:run
# 前端：Vite dev server（5174，proxy /api→8081）
cd frontend && npm install && npm run dev
```

与容器模式端口刻意错开（博客项目占 8080/5173），两项目可同机并行。

## 9. 已知边界

- compose 验证过 WSL2/Docker Desktop；Linux 服务器直接可用（去掉桌面依赖，nginx 443 需自备证书）。
- H2/内存 Redis 仅测试 profile；容器运行时一律真 MySQL/Redis。
- 首次构建冷缓存约需十几分钟（Aliyun 镜像源已配），CI 不含镜像构建（保持零中间件依赖的纯单测流水线）。
